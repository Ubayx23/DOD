Retro:

We were able to build all 4 of our planes, but only 1 was able to land on target. Looking back, we would benefit from more research and testing time. For things to improve on for the group, we think that we could build more planes in the future to increase shipping volume. We could have also had a system that made retrieving planes that missed the target easier to make testing and shipping faster. For things our professor could improve on, the guidelines for what is classified as a paper airplane could have been clearer, as some groups just balled up paper. A bigger target would have also made it easier and gave us more room for error.
